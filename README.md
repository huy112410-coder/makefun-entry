Entry for make.fun's [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154) bounty.

`main.ts` writes one line of UTF-8 text to `/output/entry.txt`: a funny autocorrect fail,
under 200 characters. Node.js standard library only, no network, no clock, no randomness.

## Run it

```sh
node main.ts
```

Set `ENTRY_OUT` to write somewhere other than `/output/entry.txt`.

## The line

> I texted my boss “I’m running late” and autocorrect sent “I’m ruining late.” He replied:
> “Finally, an accurate status update.”
